# 🍽️ Restaurant Analytics Dashboard – Power BI

An interactive **Restaurant Analytics Dashboard** built using Microsoft Power BI to explore restaurant performance, customer behaviour, revenue trends, and delivery operations.

The report brings together business KPIs and visual analysis across six pages, helping users explore operational and commercial performance through interactive filters.

## 📁 Report Pages

### 1. Executive Overview
A high-level view of restaurant business performance.

- Total Revenue
- Total Orders
- Average Delivery Time
- Average Order Value
- Revenue Trend
- Orders Trend
- Revenue by City
- Order Status Breakdown
- Top 10 Restaurants
- City-wise filtering

### 2. Customer Analytics
Explores customer acquisition and repeat-order behaviour.

- Total Customers
- Repeat Customers
- Orders per Customer
- Repeat Customer Percentage
- Customer Signup Trend
- Orders by Customer Type
- New vs. Repeat Customers
- Restaurant and table-booking analysis

### 3. Restaurant Performance
Compares restaurant performance across cuisines and other business metrics.

- Total Restaurants
- Average Rating
- Revenue per Restaurant
- Average Votes
- Orders by Cuisine
- Revenue by Top 10 Restaurants
- Average Rating by Cuisine
- Restaurant Rating Analysis
- Orders by Cost Bucket
- Online vs. Offline order filtering

### 4. Delivery and Operations
Focuses on delivery efficiency and order outcomes.

- Average Delivery Time
- Late Orders
- Cancelled Orders
- Late Delivery Percentage
- City-wise Delivery Time
- Delivery Status Breakdown
- Cancellations by City
- City-wise operational analysis

### 5. Advanced Insights
Provides additional analytical exploration through:

- Dynamic KPI selection
- KPI trend analysis
- Restaurant-level comparative analysis
- Interactive scatter plot
- Power BI Q&A visual

### 6. Restaurant Details
A detailed view of an individual restaurant, including:

- Restaurant Name
- Total Revenue
- Total Orders
- Average Rating
- Average Votes
- Average Delivery Time
- Revenue and order trends
- Customer-type analysis
- Delivery status breakdown

## 🧰 Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **DAX (Data Analysis Expressions)** – KPI calculations and analytical measures
- **Power Query** – Data preparation and transformation
- **Data Modeling** – Working with Orders, Customers, Restaurants, DateTable, and supporting tables

## 📌 Key KPIs

| KPI | Purpose |
|---|---|
| Total Revenue | Measures overall revenue |
| Total Orders | Tracks order volume |
| Average Order Value | Measures average revenue per order |
| Average Delivery Time | Monitors delivery efficiency |
| Repeat Customers | Tracks returning customers |
| Repeat Customer % | Measures customer retention behaviour |
| Average Rating | Evaluates restaurant ratings |
| Late Orders | Tracks delayed orders |
| Cancelled Orders | Monitors order cancellations |

## 🔍 Interactivity and Analysis

The report includes interactive slicers and visual-level filtering to explore performance by dimensions such as:

- City
- Date and year
- Customer type
- Restaurant
- Cuisine
- Online/offline ordering
- Table booking
- Selected KPI

The available filters vary by report page.

## 🚀 Getting Started

1. Download or clone this repository.
2. Make sure you have **Microsoft Power BI Desktop** installed.
3. Open `Restaurant.pbix` in Power BI Desktop.
4. If Power BI prompts you to update data source credentials or file paths, configure them according to your dataset.
5. Refresh the data if the original source files are available.
6. Explore the report using its slicers and interactive visuals.
